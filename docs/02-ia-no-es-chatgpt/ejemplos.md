# F2 — Ejemplos cotidianos de IA

> Material de apoyo para el bloque "La IA no es igual a ChatGPT".
> Sirve para la diapositiva de collage y para responder preguntas del público.

---

## 1. IA que usamos sin darnos cuenta

| Situación del día a día | Qué hace la IA |
|---|---|
| Netflix/YouTube te recomienda algo | Aprende de lo que viste para sugerirte lo próximo |
| Waze/Google Maps recalcula la ruta | Predice el tráfico y encuentra el mejor camino |
| El banco te avisa de un movimiento raro | Detecta comportamientos fuera de lo normal |
| WhatsApp transcribe un audio a texto | Convierte voz en escritura |
| El celular mejora una foto o pone un filtro | Reconoce rostros y ajusta la imagen |
| El correo manda la publicidad a "Spam" | Clasifica si un mensaje es basura o no |
| Tu banco o la cooperativa autoriza un crédito | Ayuda a evaluar el riesgo con datos |
| Asistentes de voz (Siri, Alexa) | Entienden lo que dices y responden |
| El teclado te sugiere la siguiente palabra | Predice lo que vas a escribir |

> **Idea para contar:** "Ustedes ya usan inteligencia artificial desde hace años.
> La novedad no es la IA; la novedad es que ahora **podemos conversar con ella**."

---

## 2. Las mismas palabras, significados distintos

| Lo que dice la gente | Lo que realmente es |
|---|---|
| "La IA" | Todo el campo: máquinas que imitan tareas del cerebro |
| "ChatGPT" | Una **aplicación** para conversar con un modelo de lenguaje |
| "Que la IA me escriba" | Un **modelo de lenguaje** generando texto |
| "Que la IA dibuje" | Un **modelo de imágenes** (FLUX, Stable Diffusion…) |
| "Que la IA me resuma un PDF" | Un modelo que lee documentos largos |
| "Un robot" | Puede ser IA, pero también puede no serlo |

> **Idea para contar:** "Igual que decimos 'voy al banco' cuando vamos a la
> cooperativa: la palabra se quedó corta. Aquí pasa lo mismo."

---

## 3. Ejemplos que conectan con la cooperativa

| Tarea de Coomultiunion | Cómo ayuda la IA |
|---|---|
| Redactar una circular para los asociados | Un modelo de texto la escribe y la pule |
| Resumir un convenio largo | Un modelo lee y resume en 5 puntos |
| Atender preguntas frecuentes por WhatsApp | Un asistente responde lo repetitivo |
| Analizar quién usa más un beneficio | La analítica + IA encuentran patrones |
| Traducir un convenio o revisar un contrato | Un modelo traduce o señala cláusulas |
| Diseñar una pieza para redes | Un modelo de imágenes genera el boceto |

> **Idea para contar:** "No se trata de reemplazar personas, sino de **quitarles el
> trabajo repetitivo** para que se dediquen a lo importante."

---

## 4. Frases de cierre para usar

- "La IA no es solo un chat; es una caja de herramientas con muchas puertas."
- "Ya la usábamos sin saberlo; lo nuevo es que ahora le podemos pedir cosas."
- "ChatGPT fue la puerta; detrás de ella hay todo un mundo."
